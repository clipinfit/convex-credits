Current stable version: [`1.0.0`](https://www.npmjs.com/package/@clipin/convex-credits), published on September 8, 2026.

The component and example pass 18 tests. Coverage includes repeated requests, key conflicts, release, partial refunds, transfers, invalid amounts, namespace isolation, account imports, and host transaction rollback. Generated operation sequences check balances against the ledger sum.

A real local Convex deployment also passes concurrent duplicate grants, competing reservations, a completion/release race, and ledger reconciliation. The website has been inspected at desktop and mobile sizes.

Installed-package verification and CI pass with Convex 1.42.1 and 1.45.0. A private production-data import rehearsal passed. The first production integration and directory submission are in progress.
